# Globe-Trotting 🌍✈️

A web project where users can visualize their travel map and interact with a “Send Your Name to Mars” style feature.

## Live Demo
[Check out Globe-Trotting](https://name-to-mars-f1420f13.base44.app/Home)

## Inspired by
[NASA’s Send Your Name to Mars](https://mars.nasa.gov/participate/send-your-name/mars2020/)

## Screenshot
![Result](https://user-images.githubusercontent.com/41951429/99184036-99673480-2740-11eb-8442-94dc5a959b21.png)

## Features
- Interactive travel map
- Submit your name to “Mars” simulation
- Fun, educational experience inspired by NASA

## Technologies Used
- HTML
- CSS
- JavaScript

## Installation / Usage
1. Clone this repository: `git clone <repo-url>`
2. Open `index.html` in your browser
3. Explore and have fun!
